# Vision MVP Frontend

Interface React/Vite para enviar imagens ao backend e visualizar deteccoes.

## Rodar

```powershell
.\start.ps1
```

Ou manualmente:

```powershell
npm install
npm run dev
```

Por padrao, o frontend usa:

```env
VITE_API_URL=http://127.0.0.1:8000
```

Se precisar mudar, copie `.env.example` para `.env`.
